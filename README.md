**Project: Year-End Project Analysis Dashboard (Excel)**

**Overview:**
This Excel-based dashboard provides a comprehensive year-end analysis of project outcomes for our organization. It visualizes the distribution of awarded and dropped projects across various sectors and tracks monthly performance.

**Key Insights:**

Sector Analysis: Pie charts illustrate the proportion of projects awarded versus dropped in sectors such as commercial, hospital, hotel, residential, retail, and workspace. This helps identify which sectors had the highest success rates.

Monthly Trends: A bar chart displays the number of projects awarded each month, offering a clear view of seasonal trends and peak periods.

Enquiry Status: Another pie chart differentiates main projects from additional add-on work, showing how many extra tasks were attached to core projects.

**Additional Features:**

Hot and Cold Pipeline: The dashboard includes a segmentation of “hot” pipelines (projects with strong client potential) versus “cold” pipelines (future prospects).

Interactive Slicers: Monthly slicers allow users to filter data by specific months to drill down into particular time periods.

**Conclusion:**
This dashboard not only provides a visual summary of yearly project performance but also serves as a tool for strategic decision-making and resource planning. It’s a great example of how Excel can be used to transform raw data into actionable insights.
